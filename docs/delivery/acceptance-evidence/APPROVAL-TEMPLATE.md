# 真实平台验收批准单（模板）

> 复制本文件为 `APPROVAL-<日期>-<批准人>.md`，填写后存档于本目录。
> 本单是执行验收的唯一凭据；未填写归档前，系统不得向真实平台发送任何内容。

```text
真实平台验收批准单
日期：____
批准人（业务负责人）：____（姓名/角色）
执行人：____

批准执行的动作用真实账号各完成一次，对象均为测试数据：
1. 抖音测试账号「____」对一条测试评论/私信发送一条真实回复；
2. 将一个测试客户真实写入飞书多维表格「____」；
3. （可选）小红书测试账号「____」执行一次低量关键词采集（≤3 视频）。

不批准的范围：主账号发布、批量发送、真实客户数据写入、任何未列出的动作。
撤销条件：出现风控提示/验证码即停止，剩余动作作废。
```

## 填写后

1. 运行 `pnpm acceptance:readiness` 确认前置条件就绪。
2. 按 [`../real-platform-acceptance-runbook.md`](../real-platform-acceptance-runbook.md) 第 3 节执行。
3. 证据归档到 `<日期>-<平台>-<能力>/` 子目录。
